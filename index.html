Sherpa-ONNX WebAssembly

This test deliberately uses an existing Sherpa-ONNX browser demo rather than another wrapper. That lets us answer the important question: can Sherpa actually generate speech quickly on this iPhone/iPad?

Use these settings first: Precision: int8 (~20 MB) Text: “Hello, how are you?” Speed: 1.0

The test opens the Sherpa browser demo directly. If it generates speech promptly on the same device, we know Sherpa/WASM is worth integrating properly into GameHub.
